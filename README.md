# 📝 Keeper Notepad 2.0  

**A lightweight, offline-first note-taking app built with React.js**  

🔗 **Live Demo:** [https://astr1cs.github.io/Keeper-Notepad-2.0/](https://astr1cs.github.io/Keeper-Notepad-2.0/)  
---

## ✨ Key Features  

- **Create & Delete Notes**  
  Add and manage notes effortlessly with a clean interface.  
- **Persistent Storage**  
  Notes are saved in your browser's `localStorage`—no server needed.  
- **Responsive Design**  
  Works flawlessly on all devices (desktop, tablet, mobile).  
- **Lightning Fast**  
  Optimized React performance for instant updates.  
- **Minimalist UI**  
  Focus on your content with a distraction-free design.

## 🚀 Getting Started  

### Prerequisites  
- Node.js (v14+)  
- npm/yarn  

### Installation  
1. Clone the repo:  
   ```bash
   git clone https://github.com/astr1cs/Keeper-Notepad-2.0.git
2. Install dependencies:
   ```bash
   cd Keeper-Notepad-2.0 && npm install
3. Start the development server:
   ```bash
   npm start
Open http://localhost:3000 in your browser.
